# Registre d'issues — Feedback Loop

> Findings cumules a travers les cycles de la boucle d'amelioration continue.
> Chaque cycle ajoute ses findings. Les issues resolues sont marquees CLOSED.

## Statuts

| Statut | Description |
|--------|-------------|
| OPEN | Finding identifie, en attente d'arbitrage ou d'action |
| IN_PROGRESS | Action en cours |
| CLOSED | Resolu (corrige, rejete, ou archive) |
| DEFERRED | Reporte a un cycle futur |
