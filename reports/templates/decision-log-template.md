## Format

Chaque decision suit ce format :

```
### DEC-YYYY-MM-DD-NNN — [Titre court]

| | |
|---|---|
| **Date** | YYYY-MM-DD |
| **Cycle** | #N |
| **Finding** | FL-YYYY-MM-DD-NNN |
| **Type** | INCOHERENCE / FAIBLESSE_SPEC / OPPORTUNITE / FEATURE / ... |
| **Decision** | Accepter / Modifier / Rejeter / Reporter |

**Contexte** : [Ce qui a ete trouve]

**Proposition** : [Ce qui etait recommande]

**Decision PO** : [Ce qui a ete decide et pourquoi]

**Action** : [Ce qui a ete fait concretement — diff, fichier modifie, ou "aucune action"]
```
